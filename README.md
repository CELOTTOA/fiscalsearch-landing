# FiscalSearch — landing

Sito informativo statico di FiscalSearch, pubblicato con GitHub Pages.

Pubblicazione dal branch `main`, cartella `/`; `.nojekyll` mantiene i file statici.
La pagina non esegue richieste AI, non raccoglie documenti e non gestisce pagamenti.

Le modifiche si preparano nella cartella `landing/` del progetto di sviluppo e si pubblicano qui copiando soltanto i quattro HTML, i quattro asset e `.nojekyll`.
